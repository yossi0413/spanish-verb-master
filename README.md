# Spanish Verb Master

楽しくスペイン語の動詞活用をマスターするための、モバイルファーストWebアプリケーションです。
サーバーレスで動作し、オフラインでも学習が可能です。

## 機能
- **ランダム練習**: エンドレスに動詞活用を練習できるモード。
- **分野別練習**: 直説法・現在など、特定の法・時制に絞って練習。
- **苦手克服**: 自分で「星」をつけた単語だけを重点的に練習。
- **辞書・データ管理**: 動詞の検索や、CSVデータのインポート/エクスポートが可能。

## 技術スタック
- HTML5, CSS3, Vanilla JavaScript (ES Modules)
- No Server, No Build, No Framework
- LocalStorageによるデータ永続化
- PWA対応 (ホーム画面に追加可能)
